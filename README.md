### Stages:

Stage de 2nd année de BUT informatiquue

J'ai fait mon stage de 8 semaines a partir du 7 avril 2026 dans l'entreprise Lima Adhésif a Couzeix.
Durant mon stage j'ai eu a effectuer plusieurs taches:
- Dans un premier temps j'ai eu a traduire des pages de leur intranet qui étaient en ASP vers leur équivalent PHP.
- Dans un second temps on m'a confié un projet dans lequel il fallait créer une page sur l'intranet pour récupérer certaines données clients et les exporter au format csv pour être par la suite envoyé a un prestataire qui gère la page internet client de l'entrprise. Ce projet a été découpé en plusieurs parties:
  - Dans un premier temps j'ai eu a analyser la base de donnée de l'entreprise qui était dans leur ERP pour savoir quelles données récupérer ou et quels relations utiliser. Puis j'ai du construire les requêtes correspondantes
  - Dans un second temps j'ai du construire la page PHP qui utilise les requêtes faites pour passer les données dans un fichier csv. En parallèle sur la page j'ai du mettre en place un tableau qui montre les données et met en avant celles non conformes pour permettre de les repérer et donc de les modifier pour les rendre conformes.
  - Ensuite j'ai du faire en sorte que les csv soient générés tous les jours en mettant en place le lancement de la génération via l'url (le clic sur un bouton passe un paramètre dans l'url qui génère les csv donc pour la génération automatique on simule le clic sur le bouton).
  - Enfin grâce a Filezilla j'ai vu comment faire en sorte de récupérer les csv générés pour les envoyer vers un serveur mis en place par le prestataire pour qu'ils les réutilisent pour les pages d'espace client.
